JavaScript Basics — 50 Questions

Variables
-------------

1.What is a variable in JavaScript?
  A variable is a container used to store a value; it may be a number, a boolean, or a string.

----------------------------------------------------------------------------------------------------------------

2.What are the three keywords used to create variables?
  1.var
  2.let
  3.const

----------------------------------------------------------------------------------------------------------------

-----------------------------------------------------------------------------------------------------------------

4.Write the syntax to create a variable using let.

-----------------------------------------------------------------------------------------------------------------

5.Write the syntax to create a variable using const.
  const c = 200;

-----------------------------------------------------------------------------------------------------------------

6.What is declaration?
  Declaration means the process of creating a variable without assigning a value to it.

------------------------------------------------------------------------------------------------------------------

7.What is initialization?
  Initialization means the process of assigning a value to a variable.

------------------------------------------------------------------------------------------------------------------

8.What is reassignment?
  Reassignment means the process of changing the value of an already existing variable.

-------------------------------------------------------------------------------------------------------------------

9.What is redeclaration?
  Redeclaration means the process of declaring the same variable again using the same keyword.

-------------------------------------------------------------------------------------------------------------------

10.Which keyword allows redeclaration?
  "var" keyword only allows redeclaration.

--------------------------------------------------------------------------------------------------------------------

11.Which keyword allows reassignment?
  "var" and "let" keywords allow reassignment.

--------------------------------------------------------------------------------------------------------------------

12.Which keyword requires initialization when declared?
  "const" keyword requires initialization when it is declared.

44.What is the difference between let and const?

 The difference between let and const is that let can be reassigned, does not require immediate initialization, and cannot be redeclared, while const cannot be reassigned, must be initialized when declared, and cannot be redeclared.

---------------------------------------------------------------------------------------------------------------------------------------

45.What is the difference between var and const?

  The difference between var and const is that var can be reassigned and redeclared, while const cannot be reassigned, must be initialized when declared, and cannot be redeclared.

50.What is the purpose of each?
   alert()
   prompt()
   confirm()
   document.writeln()
   console.log()

   Answer:
   1.alert() - Shows a message to the user in a popup box.
   2.prompt() - Asks the user to enter some information.
   3.confirm() - Asks the user to confirm an action. It returns true for OK and false for Cancel.
   4.document.writeln() - Writes content directly to the webpage.
   5.console.log() - Prints information or values in the browser console, mainly for debugging.
